# Manual coach workflow

The weekly plan and nutrition cards normally read `private/data/coach.json`,
generated by `pnpm ai coach` or the private installation's AI coach workflow.

To use the manual fallback, run these commands from the project root:

```bash
pnpm coach:prompt
```

The output contains sensitive health and training context. Only send it to an
AI service after reviewing its privacy settings and consenting to that sharing.
Ask it for the JSON object described by the prompt, then save that response:

```bash
pnpm coach:save < /path/to/response.json
```

The script validates the response before replacing `private/data/coach.json`.
Local development serves the updated artifact at `/data/coach.json`.
In a **private installation repository only**, commit the artifact and push to
trigger the authenticated deployment:

```bash
git add -f private/data/coach.json
git commit -m "data: Refresh weekly coach"
git push
```

Do not commit the prompt or response to a public repository. The next automated
coach run may replace the manual plan. To generate all current analyses in order,
run `pnpm ai all` locally or dispatch **Run all** in the private installation.
